# 키움증권 호가창 주문 프로그램 (지정가/시장가 + 분봉차트)

키움 OpenAPI+를 사용해서 **호가창 주문(지정가/시장가)** 과 **1/5/20/60분봉 차트(마우스 휠 확대/축소)** 를 제공하는 예제입니다.

## 기능
- 키움 로그인
- 호가 조회(TR: `OPT10004`) + 실시간 호가 구독
- 호가창(매도/매수 10단) 표시 및 클릭 가격 입력
- 지정가(`00`) / 시장가(`03`) 매수·매도 주문
- 분봉 차트 조회(TR: `OPT10080`) 지원: 1분/5분/20분/60분
- 차트에서 마우스 휠 스크롤로 캔들 확대/축소

## 실행 환경
- **Windows** (키움 OpenAPI+ 설치 필수)
- Python 3.9+
- OpenAPI+와 Python 비트수(32/64) 일치 필요

## 설치
```bash
pip install -r requirements.txt
```

## 실행
```bash
python kiwoom_orderbook_trader.py
```

## 사용 방법
1. 계좌번호 / 종목코드 입력
2. `로그인` 클릭
3. `호가/차트 조회` 클릭
4. 분봉 선택(1/5/20/60분) 변경 시 차트 재조회
5. 주문유형에서 `지정가` 또는 `시장가` 선택
6. 수량 입력 후 `매수` / `매도`
   - 지정가: 가격 입력 필요
   - 시장가: 가격 0으로 주문 전송

## 주의 사항
- 반드시 모의투자 환경에서 충분히 검증 후 실거래에 사용하세요.
- OpenAPI 서버/환경에 따라 TR 출력 필드명이나 실시간 FID 해석은 보정이 필요할 수 있습니다.
- 체결/잔고 이벤트(`OnReceiveChejanData`)는 필요시 추가 구현하세요.
