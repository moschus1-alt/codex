# 키움증권 호가창 주문 프로그램 (기본형)

키움 OpenAPI+를 사용해서 **호가창을 보고 클릭한 가격으로 주문**할 수 있는 최소 예제입니다.

## 기능
- 키움 로그인 요청
- 종목 호가 조회(TR: `OPT10004`) + 실시간 호가 구독
- 호가창(매도/매수 10단) 표시
- 호가 클릭 시 주문가격 자동 입력
- 지정가 매수/매도 주문 전송(`SendOrder`)

## 실행 환경
- **Windows** (키움 OpenAPI+ 설치 필수)
- Python 3.9+
- 32bit/64bit Python은 설치된 OpenAPI+ 환경과 맞춰 주세요.

## 설치
```bash
pip install -r requirements.txt
```

## 실행
```bash
python kiwoom_orderbook_trader.py
```

## 사용 방법
1. 키움 HTS/모의투자 환경 로그인 가능 상태에서 프로그램 실행
2. 계좌번호 입력 (하이픈 없이)
3. `로그인` 클릭
4. 종목코드 입력 후 `호가조회` 클릭
5. 호가창 가격(매도호가/매수호가) 클릭 -> 주문가격 자동 입력
6. 수량 입력 후 `매수` 또는 `매도`

## 주의 사항
- 이 코드는 **기본 샘플**입니다. 실거래 전 반드시 모의투자로 충분히 검증하세요.
- 호가 FID/필드명은 환경에 따라 다를 수 있어, 실시간 호가가 비정상일 경우 FID 매핑을 조정해야 합니다.
- 주문 응답/체결/잔고 이벤트 처리(OnReceiveChejanData)는 필요 시 추가하세요.
