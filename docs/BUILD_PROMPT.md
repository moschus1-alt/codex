# 후속 제작 지침

사용자가 확정한 범위는 토스 Open API, GitHub 소스, Vercel 호스팅, 라오어 V2.2 40분할이다. 7슬롯 세븐스플릿으로 바꾸지 않는다. 기존 토스 프로그램의 PAPER 기본, LIVE 잠금, 최대 6종목, 공통→종목별 설정, 모바일/PC 대시보드, 거래 사유 로그를 유지한다.

이 프로젝트는 원문 검증 미완료 계산안 + 사용자 확인 주문 웹앱이다. 완전 자동매매라고 표현하지 않는다. 원문 규칙을 확보한 후 T의 정의·부분매도·초기 진입·센트 보정·쿼터손절·복귀부터 검증한다. 검증 없이 STRATEGY_RULES_CONFIRMED 기본값을 true로 바꾸지 않는다.

다음 개발 순서:
1. 원문/사용자 승인 예제를 기반으로 독립적인 정답 데이터와 계산 테스트 추가.
2. 토스 MOC 지원과 LOC 매수·매도 동시 주문 가능 여부를 공식 문서/계좌에서 확인. 미지원 기능을 LIMIT/MARKET로 임의 대체하지 않기.
3. UNKNOWN/SUBMITTING 복구: 사용자 확인 주문ID 결합, 중복 방지, 주문·체결 재조정. 증권사에서 미접수 증명 전 재전송 금지.
4. 수동 주문 실계좌 검증 후에만 예약 자동실행 추가. 시장 캘린더·조기폐장·DST·접수 마감·분산 잠금·장기 내구성·휴일·일별 자금 예약이 필수.
5. 브라우저 실검수: 모바일 폭, 로그인, 모의 잔고, 설정 오버라이드, 주문표·CSV·오류·새로고침, 다중 탭 충돌.

원문·예제의 검증된 내용과 현재 코드 차이를 문서화하고, 구현되지 않은 기능을 UI에서 활성화하거나 완료했다고 쓰지 않는다. 실제 키를 코드·로그·클라이언트로 내보내지 않는다. 요청 전 장부 기록 및 응답 불명 시 차단을 유지한다.
